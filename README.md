☕ SeruputinAja.

SeruputinAja. adalah project sistem website kedai kopi yang dirancang untuk memudahkan proses pemesanan dan pengelolaan operasional kedai secara digital.

Melalui sistem ini, pelanggan dapat menjelajahi daftar menu, memesan kopi secara online (makan di tempat maupun bawa pulang), hingga memantau status pesanannya secara langsung. Di sisi lain, sistem ini juga menyediakan panel khusus bagi pengelola (admin) untuk mengatur ketersediaan menu, memproses pesanan masuk, dan memantau laporan penjualan harian.
